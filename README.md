# Green Roots

## Stack

- `api/` — TypeScript, Bun, Elysia, Drizzle, Zod
- `web/` — TypeScript, Bun, React, React Router, Tailwind CSS, Tanstack Query

## Commandes

```bash
make build    # premier démarrage ou après modif du Dockerfile/package.json
make start    # démarrer
make stop     # stopper sans supprimer les conteneurs
make down     # stopper et supprimer les conteneurs
```
